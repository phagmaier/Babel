# M2-05C synthetic native snapshot proof

This diagnostic uses the existing disabled-by-default `editor-composition-proof`
feature to initialize only a marked synthetic root. Production writer/destination
selection stays unavailable. No frontend command accepts a path. The additional
proof-only destination command selects the fixed private `data/` folder under
that validated root. No network, Git or personal source is used.

Seed a fresh root using `python3 prototypes/editor-composition/seed.py` (tmpfs),
or supply a known owned Btrfs base directory as its argument. Use the root printed
by that command as `BABEL_EDITOR_COMPOSITION_ROOT`, then run
`pnpm tauri dev --features editor-composition-proof --config src-tauri/tauri.snapshot-proof.conf.json`.
Redirect its output to a task log. The real WebKit window must show the native
snapshot panel and same-filesystem explanation. Native folder picking is not
implemented by this diagnostic.

With the owned proof window focused, run
`python3 prototypes/snapshot-review/native-smoke.py <log> <root>`.
It sends a real Wayland F2 keystroke, which drives the native snapshot/copy/restore/
prune/reopen commands. The independent Python audit compares literal original,
restored and live-protection bytes, SHA-256 metadata/blob/frame checksums, exact
receipts, source previous-copy and reopened session. Expected outputs are literal
suffixes in the audit, not generated by the implementation. Use a new root for
each drill; the source is deliberately replaced with synthetic restored bytes.

Manual controls use the same `SnapshotPanel` and native adapter as the future
open controller. Enter a name for a snapshot, explicitly choose a new restore
version, or save a copy to the fixed diagnostic destination. F2 is only for a
fresh untouched diagnostic session, not after a manual restore. Injected UI tests
are separate from this real native smoke; neither establishes full editor/close,
installed-package, other-platform or hardware power-loss support.

Archive the owned synthetic root outside the repo before cleanup and stop its
owned native process first. Exact executed commands, host, archives and results
are recorded once in [M2 evidence](../../docs/test-evidence/M2-05C.md).
