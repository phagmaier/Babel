## Acceptance

- Scene heading/body/attached synopsis/notes follow documented boundaries; scenes never absorb an adjacent act/section. Sections move complete nested subtrees. Dual dialogue, omitted/raw regions, explicit numbering, blank bytes/BOM/endings/EOF and inline marks retain correct ownership and semantics.
- Preview exactly what moves when attachments are ambiguous; refusal preserves original/candidate review copies when faithful serialization is unavailable. No hidden conversion, separator normalization, unsafe partial group or cross-document drop.
- Drag-and-drop and keyboard move commands use the same plan. Large moves await M4-04 safety revision; read-only, composing, stale or failed-protection commands refuse. Selection follows the moved region and one Undo/Redo restores full source/selection while versions advance.
- Move invalidates/recomputes indexes, completion and diagnostic projections. Source Save after move/Undo/reopen independently reproduces expected bytes/order; unrelated source regions remain exact.
