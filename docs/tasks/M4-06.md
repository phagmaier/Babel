## Own and deliver

Title field add/edit/remove commands and bridge support, `src/app/TitlePagePanel.tsx`, focused contract/UI tests. Form edits are EditorState transactions, with temporary uncommitted input clearly identified and protected before navigation/close.

## Acceptance

- Edit standard fields, multiline continuations and empty values; add/remove/reorder only by explicit action. Retain duplicate/unknown keys, authored order, untouched indentation, emphasis, BOM/newlines/EOF and body bytes. Ambiguous/unrepresentable changes refuse visibly without falling back to normalized source.
- Opening/closing the form is a byte no-op. Committed edits advance versions and have coherent Undo/Redo/selection; staged input is never treated as saved or lost on switch/close. No independently mutable committed title-content store.
- Read-only/composing/stale form submissions refuse. Save/recovery/restore/reopen and immediate Save after Undo retain exact content; global shortcuts do not steal form typing/IME. Keyboard labels, focus/escape and errors work in the native app.

## Verification

- `pnpm exec vitest run tests/contract/title-page.test.ts tests/ui/TitlePagePanel.test.tsx tests/contract/editor-bridge.test.ts`; independent title literals and M4-00 shared checks.
- Native form/IME/cancel/Undo/Save/reopen and failure inspection; reuse source safety matrix without adding a new filesystem adapter. Evidence: [M4](../test-evidence/M4.md).

## Excludes

PDF title-page layout/glyph support (M5), silently canonicalizing unknown fields and a second raw-source editor.

## Delivered and evidence

Explicit field edit/add/remove/reorder commands retain complete exact source regions and use isolated sole-editor transactions. Staged input is visibly memory-only and blocks leaving/source saving/import/restore until Apply/Discard; read-only/composing/stale actions refuse. Independent contract/UI and shared checks plus default embedded WebKit/GTK form, real pinyin commit/cancel, exact Save/Undo/restore/reopen, divergence/recovery/Save As and read-only inspection passed on tmpfs/Btrfs. [M4-06 evidence](../test-evidence/M4.md#m4-06--source-preserving-title-page-form) owns commands, failed attempts, artifacts and omissions. PDF and full M4/accessibility/performance acceptance remain outside this bounded task.
