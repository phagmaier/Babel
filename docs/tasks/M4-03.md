## Own and deliver

Focused source/index/controller/UI tests and default-release native drills verify the change. Index exposes scene/section hierarchy, synopsis attachments and logical author-text locations for later find/diagnostics/counts without a second editor authority.

## Acceptance

- Define scene boundaries at section boundaries as well as subsequent headings; section subtrees follow nesting depth. Explicit synopsis/note/blank attachment policy marks ambiguity for later move previews; dual groups and protected/raw ranges are represented intact.
- Nested/collapsible/searchable outline displays synopsis and distinct ordinal/authored scene numbers. Keyboard/click navigation changes selection/viewport only, with exact Unicode anchors and focus return; empty/no-scene/duplicate-number drafts work.
- Coalesced/bounded projections carry session/version/hash and reject stale results after edits/Undo/import/restore/switch. Include title/note/omitted/raw text locations without discarding unknown content. In-memory drafts that cannot capture show unavailable/stale projections, never substitute old source as current.
- No whole-source parse/index rebuild in a key handler or synchronous transaction filter. Measure typical and stress index/navigation latency; visible find/navigation target is 200 ms with source size/method recorded. Bounds never silently report truncated results as complete.
