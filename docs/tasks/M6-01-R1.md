# M6-01-R1 Supported-runtime shutdown follow-up

Status: **blocked — no supported corrected runtime verified; no implementation in M6-01**
Dependencies: M6-01 review/evidence; an actually available supported Linux runtime containing the relevant upstream correction, exact target scope and authorization for any dependency/runtime change
Requirements: SAVE-05, QA-01/02, SEC-02; preserve INV-04/05/06/10/18

## Trigger and scope

C1 parent SIGKILL and F2 active WebDriver DELETE bypass the accepted-close
mitigation. M6-01 retains both findings and keeps release gate C open; new clean
samples cannot erase historical failures. Read [M6-01](M6-01.md),
[ADR 0035](../decisions/0035-linux-web-process-close.md) and
[M6 evidence](../test-evidence/M6.md).

Before changing anything, verify the supported runtime's release/packaging and
patch inclusion from primary sources and actual mapped binary identities.
An upstream fixed bug alone is insufficient. Freeze old/current binaries and
one candidate, one supported mitigation at a time. Do not begin a private
WebKit distribution, broad graphics bisection or system package installation.
A necessary application/dependency correction gets a narrowed scope addendum
with demonstrated reachability before coding.

## Acceptance and checks

Repeat SHUTDOWN-RETAINED ordinary/restart, C1 kill/recovery and F2 forced DELETE
on tmpfs/Btrfs with the matched non-WebDriver control, owned PID/start tokens,
bounded stderr/kernel/coredump scans and independent current/source/previous/
acknowledged-recovery byte audits. Preserve failed roots and all core identities.
Record mapped stack hashes, missing symbols, workload omissions and exact phases.
Run focused/shared/Tier 3 checks from M6-00 for any code/runtime change; packaging
changes also require actual installed/offline checks before release admission.

A reviewed disposition must explicitly name C1 and F2 and its limits. Neither
ordinary close nor intact bytes nor a non-reproducing control resolves them.
Until supported correction or explicit release review is verified, keep C open
before M6-14/16. Independent M6-02 safety work may proceed from the M6-01 review.

## Excludes and stopping

No history workflows, unrelated upgrades/refactors, private engine shipping,
crash suppression, forced system updates, global settings or milestone admission.
Stop after one supported candidate and its bounded review; additional candidates
need a new explicit scope. Missing availability/identity/native proof stays blocked.
