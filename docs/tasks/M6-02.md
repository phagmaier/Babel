## Interrupted restore coverage gap

Source replacement and snapshot publication have child-kill tests, but the
actual local-restore operation lacks a stage-bound kill check after protecting
its original disk/live generations. Thread the existing private save-stage
closure through save-request and snapshot-restore helpers, preserving public
admission/error behavior with an unconditional no-op in production. No IPC,
runtime environment hook, schema or new adapter. Kill the real restore child
before candidate publication, before replacement and after replacement; restart
must preserve independent literal original/live/selected bytes and their verified
records, with no inferred receipt. Rebuild and repeat final candidate checks.

Register opt-in `persistence-two-instances`: park one default native app with
a writable selected source, launch a second owned WebKitWebDriver/default app
with a separate disposable profile, and open the same synthetic file. Verify
read-only ownership/no edit authority in the second app, close it normally,
then save an independent edit through the still-owning first app. Both drivers
remain descendants of the tracked drill; shared stderr and journal audits cover
them. No personal app or manuscript is used.
