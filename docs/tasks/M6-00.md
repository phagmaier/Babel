## Verification policy

Use [development tiers](../development.md#check-tiers-use-the-lowest-tier-that-covers-the-change).
Routine local changes use focused tests and applicable static/native checks;
full frontend/Rust/helper/browser suites belong to CI/integration/release.
Final milestone gates retain their integrated checks. Native changes build the
default production app; packaging requires installed/offline validation and
verified resources. No proof features or embedded dev automation may ship.
Use a compact evidence table under `docs/test-evidence/`; link it from M6 status
instead of repeating results. Preserve all historical M6 evidence.
IPC, source/recovery/journal/snapshot/history publication, identity/lease/metadata,
interruption and packaging trigger Tier 3. Run affected filesystem tests and named real
native drills on verified tmpfs and Btrfs synthetic roots, using existing
`BABEL_SAVE_TEST_ROOT`, `BABEL_RECOVERY_TEST_ROOT`, `BABEL_STARTUP_TEST_ROOT`,
`BABEL_CHOICES_TEST_ROOT`, `BABEL_SNAPSHOT_TEST_ROOT`, `BABEL_HISTORY_TEST_ROOT`,
`BABEL_IPC_TEST_ROOT`, `BABEL_APP_DIR_TEST_ROOT`, `BABEL_RECENT_TEST_ROOT`,
`BABEL_SPELLCHECK_TEST_ROOT`, `BABEL_PUBLICATION_TEST_ROOT` and
`BABEL_PDF_TEST_ROOT` as applicable. Verify actual mounts and selector support;
do not infer two filesystems from two directory names. Extend selectors for new
stores explicitly when implementing. Each declared OS/architecture needs its
own adapter/filesystem/native evidence; tmpfs/Btrfs is Linux coverage only.

Briefs name **planned drill IDs**, not existing CLI flags. Add their exact
invocations and prerequisites to the existing native guide and evidence when
implemented. Reuse current shutdown/lifecycle/input/commands/publication runners
and independent byte/ref/selection oracles; no harness repackaging. Retain every
failed run and audit crashes even when content checks pass. New goldens require
independent review; do not accept implementation-generated expectations blindly.
Final M6-16 refreshes integrated checks on the final candidate; historic evidence
can support unchanged scoped contracts only with explicit justification.
