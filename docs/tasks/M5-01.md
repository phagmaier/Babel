# M5-01 Bundled offline renderer helper

Status: **planned**
Dependencies: M5-00; ADR 0009 baseline
Requirements: PDF-01/04, SEC-01/02, QA-01; INV-03/13/14

## Read

- SPEC S01 (no assumed end-user Python/Node), S12.1–2, S14/S15 packaging and license obligations
- ADR [0009](../decisions/0009-pdf-renderer-baseline.md), [M1-03 harness](../../prototypes/pdf/README.md) and [coverage](../../prototypes/pdf/COVERAGE.md), [development](../development.md)

## Own and deliver

A self-contained renderer helper (planned `tools/pdf-helper/`) pinning
Screenplain 0.12.0, ReportLab 4.4.7 and their transitives with hashes, the
Courier Prime family by file hash, and a reproducible build that produces one
executable artifact. That artifact is included in the Tauri bundle without a
system Python. The helper protocol is fixed: source bytes on stdin, a small
JSON request (profile/font IDs, options) on argv or stdin, PDF bytes to an
app-provided output path, and JSON result/warnings on stdout. There is no
shell, no interpolated arguments, no network and no writes outside the given
output path. Record the packaging choice and transitive license inventory
(MIT/BSD/OFL, pillow, charset-normalizer) in a new ADR.

## Acceptance

- The built helper renders the M1-03 corpus with Letter page sizes and text
  order matching the M1 observations, on the reference host with no Python on
  `PATH`, inside a network namespace.
- Build is reproducible from pinned inputs: rebuilding gives the same helper
  hash, or the differences are explained and bounded. Font files are verified
  by hash at build and at startup.
- Malformed/oversized input, missing fonts, timeouts and helper crashes return
  typed errors. The helper never touches any path but its output.
- Size, cold-start and render timings are recorded as background measurements only.
- **Gate:** if bundling fails on the platform, license or conformance checks,
  stop, record the failure and ask the owner whether to revive the pdf-lib
  fallback (ADR 0009). Do not patch around it silently.

## Verification

- Planned helper self-test (`tools/pdf-helper/` test command) plus an offline
  `unshare --net` corpus render, a `pnpm tauri build` package-content check and
  a license inventory audit. Native filesystem matrix is not applicable: the
  helper writes one owned temporary file.
- Evidence: [M5](../test-evidence/M5.md).

## Excludes

Profile/pagination changes (M5-03), native job service (M5-02), UI, other
platforms' installers (M6) and code signing.
