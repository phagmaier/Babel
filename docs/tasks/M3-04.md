## Acceptance criteria

- Stable IDs across edits/undo
- Source spans and UTF-16/UTF-8/grapheme anchors agree
- Selection and raw/protected-region behavior preserve text
- Undo/redo create newer persistence versions
- Stale serialization/hash results cannot replace newer state
- Full serialization/hashing stays outside synchronous input handlers
- No mutable peer buffer or proof imports in production
