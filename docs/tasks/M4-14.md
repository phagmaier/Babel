Status: **open**
Dependencies: M4-02/05/06/08/09/10/12/13
Requirements: NAV-03, EDIT-03, UX-01, APP-02, QA-01/02; INV-03/05/10/11/14/17/18

- SPEC S07.4/S08/S14.3/S15.4
- [UX](../ux.md), [editor behavior](../editor-behavior.md), [architecture](../architecture.md), ADR [0022](../decisions/0022-local-shortcut-preferences.md)

## Own and deliver

Command palette and command dispatch/availability integration, native menu event bridge with strict known command IDs, focus/accessibility corrections across owned M4 UI and planned palette/menu/UI tests. Use existing remappable registry for action names/help/accelerators; no new manuscript authority.

## Acceptance

- Palette filters enabled actions and scene/navigation targets; all essential workflows work by keyboard with predictable Enter/Escape/F6/Tab/focus return. Home/editor/menu/palette invoke the same application services; read-only/composition/busy/failure availability is current and honest.
- Native menu accelerators/help follow registry remaps without a second independent binding table or double dispatch. Exclude reserved OS/assistive chords and do not steal input/IME from forms. M5/M6/M7 actions remain visibly unavailable until implemented.
- Inspect semantic labels, focus order/visibility, dialogs, outline, completion, search, Script Check and persistent save/recovery errors; verify contrast, non-color indicators, reduced motion and scaling. Record actual assistive-technology behavior; absent screenreader coverage remains an explicit open gate.
- Cancellation/stale menu/palette actions cannot switch sessions, apply old projections or bypass protected close. Host accepts only known action identifiers, never arbitrary paths/shell/source payloads. No new broad capabilities.

## Verification

- Planned `pnpm exec vitest run tests/contract/command-dispatch.test.ts tests/ui/CommandPalette.test.tsx tests/ui/EditorControls.test.tsx`; strict native menu dispatch/remap tests and M4-00 shared checks.
- Actual default native keyboard/menu/palette/remap/IME/focus/scaling and available screenreader inspection; publication behavior reuses established safety matrix. Evidence: [M4](../test-evidence/M4.md).

## Excludes

IDE-like tools, general plugins, unverified OS menu support, remote/PDF/history activation and bypassing failure dialogs.
