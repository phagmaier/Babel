## Acceptance

- Provide optional explicit native-selected backup destination, disable/change controls and native-owned persistent authorization with revalidation after restart. No frontend arbitrary path or silent fallback destination.
- Publish changed snapshots off the typing path through the existing exclusive verified-copy procedure; deduplicate, bound/coalesce the queue and report last confirmed copy/version plus failure separately from local Save.
- Removed/substituted/read-only/full destinations retain local protection and never block source saving. Configuration and destination paths stay out of curated history/logs; no credentials or network scheduler.
- Explain same-filesystem storage and unknown physical disk independence. Never infer a separate disk from a different device ID. Record the lasting destination/cadence ownership choice in an ADR before implementation.
