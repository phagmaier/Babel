## Own and deliver

An integrated native publication scenario added to the existing
[writing-lifecycle harness](../../tests/native/writing-lifecycle/README.md),
the full S12.6 evidence, a dated separate review, and final status/trace updates.

## Acceptance

- The supported corpus produces faithful Letter output: page size and count,
  text presence and order, selected bounding boxes, no clipping, reviewed image
  goldens, selectable text and only the intended embedded fonts. Output is
  readable in at least two independent viewers (Poppler and Ghostscript or MuPDF).
- Preview and export from the same captured version agree. Stale-job races are
  covered. Unsupported cases block with clear warnings before export.
- The built package exports offline on the reference Linux host with no
  development runtime (network namespace, no system Python).
- The separate review covers content loss, stale-version races, helper
  privilege/egress, lossy rendering, missing failure tests and contract drift.
  This is not a second-reviewer claim. Unresolved required failures keep the gate open.
