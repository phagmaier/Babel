## Deliverable

Bounded coalescing with separate recovery/source receipts, explicit Save flush, rolling snapshot triggers using existing retention policy.

## Acceptance criteria

- Targets ~500 ms recovery coalescing, <=1 s ordinary recovery acknowledgement, ~750 ms source debounce and <=2 s continuous-typing delay measured, never asserted as power-loss guarantees
- Explicit Save/close bypass timers; unchanged source avoids replacement while explicit Save verifies a fresh flush
- Draft metadata/undo advance versions; stale captures/acks cannot clear later edits
- Saturation and source failure leave latest raw protection available and visible
- Snapshot/copy errors remain separate from save state

## Verification

- Deterministic clock/queue/race/failure tests
- Measured real native save/recovery latency under synthetic continuous typing on tmpfs/Btrfs
