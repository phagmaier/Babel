## Own and deliver

Pure stable diagnostic rule model/evaluator in `src/domain/`, versioned application controller, planned ScriptCheckPanel and issue decorations/navigation, focused diagnostic/UI tests; update the rule catalog with actual severities and false-positive boundaries.

## Acceptance

- SC001–004/006 and optional SC007 have positive/negative/incomplete-draft fixtures. Blank lines alone are not errors; unfinished speech is at most a warning. Style advice is optional/dismissible; system/save/recovery errors remain separate.
- SC005/SC008 use a typed renderer/profile/font assessment boundary with provenance; M4 may report independently verified candidate limitations but cannot infer unsupported glyphs from Unicode alone or claim a successful production export check. Until M5 connects verified rendering, display export assessment unavailable. M5 owns completion of those two rules.
- Each result carries identity/session/version/hash, stable code, severity, explanation and exact source/block navigation target. Counts/filters/grouping are bounded/honest. Stale results recompute or show stale; navigation reveals hidden/title content without editing it. No page references without a matching layout map.
- Running checks leaves source, files and cursor unchanged, never blocks Save/recovery and performs no network request. Go to Issue is explicit. No fix is required for the baseline; every result declares whether a verified safe fix exists. Any offered fix needs preview, current-version revalidation, one Undo step and positive/negative/Undo tests; no speculative Fix All.

## Verification

- Planned `pnpm exec vitest run tests/contract/script-check.test.ts tests/ui/ScriptCheckPanel.test.tsx`; independent diagnostic literals, no-op source/cursor assertions, save-with-warning and stale tests; M4-00 shared checks.
- Native Script Check/filter/keyboard/navigation/save-with-warning inspection and bounded latency. Pure evaluator needs no second filesystem run. Evidence: [M4](../test-evidence/M4.md).

## Excludes

Actual PDF rendering/font scanning/blocking export orchestration (M5), AI/style criticism, automatic fixes and hidden source conversion.
