## Acceptance

- Only successful native open/publication registers a recent entry. Save As updates identity/location after exact success; cancellation/rollback leaves old entries intact. Deduplicate by documented native identity policy, including loose files and managed projects; unsaved drafts stay distinct recovery entries.
- Entries carry safe display metadata, last-known local modification and explicit availability/unknown states. Rust does not parse Fountain; title labels may be supplied only as bounded derivatives, never canonical authored content. No fabricated page count or content scan on warm launch.
- Remove deletes only auxiliary registry metadata. Locate uses native selection/revalidation, preserves identity/leases/recovery, and explicitly presents mismatched/different selected files rather than guessing by title or timestamp.
- Corrupt/oversized metadata, symlinks/unsafe anchors, concurrent instances, permission errors and interrupted metadata publication preserve prior valid data and leave ordinary source/recovery operations usable. Bound entry counts/jobs and exclude full paths/content from logs.
