## Acceptance

- Bind the selected source/profile and current live/disk generations to native authority. Before replacement checkpoint current live bytes, preserve current live/disk snapshots and safety revision, retaining live editor state until exact success.
- Restore through the existing serialized writer as a newer version and publish a new child revision preserving former head and all later ancestry; never reset/checkout away history. Define interruption ordering before coding and record any lasting protocol choice in an ADR.
- Announce explicit undo reinitialization/rebase boundary; failed/cancelled/stale/diverged/unsupported restore preserves current editor and all protected generations with no false source-save receipt.
- Crash at each protection/source/new-child/ref stage; restart can identify both former and selected drafts and finish only through explicit review. Demonstrate restoring former current content afterward.
