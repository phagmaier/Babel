## Deliverable

Activate core New/Open/editor/Save/Save As/export copy only through passed services; connect startup recovery, external divergence, snapshots/emergency copies and protected close to the current editor.

## Acceptance criteria

- Save As cancel/failure retains old active session; successful identity switch invalidates old captures/receipts and preserves selection/appropriate undo boundary
- Close/switch freezes then protects the latest version, never bare-releases dirty text; retry/copy/risk are persistent and accurate
- Recovery/restore/import protect current content and establish explicit editor history boundaries
- History failure does not block normal/emergency saving
- Managed recovery is discoverable after open/restart, both external versions survive and status distinguishes recovery/source/snapshot/history
