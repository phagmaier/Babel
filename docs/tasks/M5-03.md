## Own and deliver

Versioned profile `us-letter-draft-v1` in the helper: exact coordinates,
baseline/line metrics, columns, title-page template, numbering, keep rules and
continuation. Implement it as a documented, pinned patch layer over Screenplain
(no new paginator), with an ADR recording the rules and patch boundary. Build a
synthetic publication corpus (planned `fixtures/publication/`) and a golden
harness that asserts layout/text/bounding boxes and compares reviewed rendered
page images.

## Acceptance

- Speech split across pages adds a profile `(MORE)` and repeated cue
  `(CONT'D)`, and never duplicates author-written continuation text. These
  markers are layout artifacts, never written back to Fountain.
- A multi-page title page leaves the first body page unnumbered. Headings keep
  with following content when feasible; cues and parentheticals are never
  stranded. An oversized unbreakable unit splits deterministically; it never
  loops, clips, shrinks or omits content.
- Lyrics `~` and the first-pair dual `^` no longer leak. If either can't be
  rendered faithfully, it is declared to M5-04 as unsupported. Dual dialogue
  stays aligned across a page; otherwise it is declared unsupported.
- Only the pinned Courier Prime faces appear in content streams. The unused
  Helvetica resource is removed, or proven unused and recorded.
- The corpus covers every S12.4 case. Goldens are independently reviewed.
  Identical inputs give identical layout and text; PDF metadata may vary.

## Verification

## Excludes

A4 or other profiles, source maps/editor markers, matching any commercial
app's page breaks, and runtime assessment UI (M5-04).
