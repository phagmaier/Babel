## Acceptance

- New/Open/Recent/Locate/Remove and local recovery are keyboard accessible with clear loading, missing, read-only, failure and cancel states. Selecting another project uses existing protected-close/lease release; stale entry/picker/recovery responses cannot switch a newer session.
- Recovery continues to revalidate full bytes, offer explicit Resume/Keep/Recover/Copy as applicable, preserve original candidates and explain local storage versus separate backup. Preview truncation is never adoption truncation.
- Unsaved drafts remain discoverable through recovery; New with a destination uses native Save As publication, with honest protection wording on cancel/failure. Remove from Recents never deletes source/recovery. Home shows no current page-count or remote-success fiction.
- Warm home usable time targets approximately 2 seconds on the recorded reference fixture/host; record actual result and blocked measurements. Initial UI reads are bounded/asynchronous and do not scan every manuscript.
