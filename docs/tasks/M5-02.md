Status: **complete on the bounded Linux host**

## Own and deliver

A native publication service (planned `src-tauri/src/publication_host.rs`
plus core types) and a typed frontend port (planned
`src/application/publication.ts`). The request binds immutable captured
source bytes, document/session identity, version and source hash, profile
version, font identities and options. The result carries an app-owned PDF
artifact handle (never a frontend path), actual page count, renderer/profile/font
identities, structured warnings and `sourceMap: unsupported`. One bounded
worker runs jobs: a newer request supersedes and cancels older ones, and
results carry the exact request identity.

## Acceptance

- A stale or cancelled job can never replace a newer result. Version and hash
  checks are enforced natively and in the port.
- Rendering never blocks typing (INV-14), never reads the live editor (it gets
  a captured snapshot) and never writes, renames or locks the manuscript or its
  recovery files. Helper failure, timeout and crash yield typed errors that
  leave source, save state and recovery untouched.
- IPC carries no paths, shell strings or source logging. Artifacts live in an
  app-owned cache with a bounded size and are cleaned up on supersede/close.
  There are no new filesystem capabilities.
- Page count and artifact are reported only for the exact version rendered
  (INV-10).
