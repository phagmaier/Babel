## Deliverable

Internal structured and external plain-text paste, sanitized HTML, distinct import-as-Fountain, undoable emphasis, measured native composition/selection behavior.

## Acceptance criteria

- Literal dialogue paste is not automatically Fountain
- Scripts/attributes/remote images never execute or fetch
- Imported content retained with safety revision and explicit undo boundary
- Multiline/Unicode/grapheme/RTL/dead-key and real IME commit/cancel/Enter, selection replacement, formatting and undo/redo exercised on recorded native host
- Missing IME/platform prerequisites remain blocked; a dead-key proof alone is insufficient

## Verification

- Native input matrix and S13 latency measurements
- Browser/mocks separately labeled
