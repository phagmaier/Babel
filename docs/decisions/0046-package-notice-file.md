# ADR 0046: Package notice file and bundled-library licence record

Status: **Accepted direction; implemented in M6-14 2026-10-06**
Date: 2026-10-06. Task: [M6-14](../tasks/M6-14.md) (notices, with M6-10).
Decided by the working agent under [ADR 0043](0043-agent-decision-authority.md).
Refines [ADR 0045](0045-user-install-and-packaged-spelling.md);
[evidence](../test-evidence/M6-14-notices-2026-10-06.md).

## Context

The AppImage redistributes about 140 third-party items: the linuxdeploy
native closure (WebKitGTK/GTK/Enchant/Hunspell and their transitive
libraries), the staged Hunspell provider, statically linked libgit2, the
python-build-standalone CPython runtime with its wheels and fonts, the
frontend JS runtime and the linuxdeploy launcher. Exact notices before any
distribution were open M6-10 work, and ADR 0045 named "package has no notice
file" as the blocker for bundling a dictionary.

## Decision

- **Notice file: `THIRD-PARTY-NOTICES.md`, Markdown, generated, shipped as a
  Tauri resource.** The tracked source is `docs/third-party/NOTICES.md`,
  generated by `tools/build-package-notices.py` from
  `docs/third-party/package-inventory.json`; `src-tauri/tauri.conf.json`
  maps it to `THIRD-PARTY-NOTICES.md`, which lands beside `pdf-helper/` at
  `usr/lib/babel/THIRD-PARTY-NOTICES.md` in the package. Markdown was chosen
  because it reads as plain text and matches the repo's docs; the file is
  self-contained (every retained text embedded in fenced blocks).
- **The desktop app surfaces it read-only.** A narrow `third_party_notices`
  IPC command returns the resource file's bytes; the frontend never sends a
  path and gains no filesystem or shell permission. A `Tools`-group
  `Third-party notices` catalog entry reaches the palette and the native
  menu; the same entry opens a lazy read-only dialog from Home (status card
  link) and from the writing view. A missing or empty file is an explicit
  unavailability, never invented content.
- **The record is derived from the artifact, not memory.**
  `tools/build-package-notices.py` extracts the AppImage inventory (every
  ELF, provider module and font), maps each file to its providing Arch
  package through pacman, and retains each licence text verbatim under
  `docs/third-party/package-licenses/` in the existing table style
  (`package-libraries.md`, `package-inventory.json`). No text was written
  from memory: project files come from the installed packages, the pinned
  pdf-helper inputs, node_modules or SHA-256-pinned upstream fetches.
- **Redistribution obligations versus host prerequisites are explicit.**
  Everything bundled (native closure, static libgit2, interpreter and its
  static components, wheels, fonts, JS runtime, launcher) is a
  redistribution obligation with a retained text. Libraries the app links
  but the bundler leaves out (libc, libm, libz, libX11, fontconfig,
  freetype, GL, DRI, FUSE support) and dictionaries stay declared host
  prerequisites with no retained text, since nothing is redistributed.
- **`tools/check-package-notices.py` gates the build.** It fails when a
  bundled library, module or font matches no manifest entry, when a
  referenced text is missing, when the in-package notice file is absent, or
  when the pdf-helper pins changed without regenerating notices. It checks
  coverage and presence only, never exact bytes or versions, so the
  Arch-authored manifest also gates the Ubuntu CI package; version drift is
  a warning. It runs in CI right after `tools/check-package-spellcheck.py`.

## Alternatives

- Plain-text notice: equivalent legally, but Markdown renders in the repo
  and reads identically as text; the in-app dialog shows it unstyled either
  way.
- `include_str!` instead of a resource file: simpler packaging, but then no
  notice file exists inside the package to extract or check; the task
  requires the file.
- Byte-exact cross-host check: fails on any legitimate rebuild (Ubuntu
  ships different library versions), so coverage was chosen.

## Consequences

- **Dictionary bundling is mechanically unblocked but declined.** The notice
  file and the CI gate remove ADR 0045's stated blocker, yet dictionaries
  stay host-provided: bundling one language adds dictionary licence texts
  for partial coverage while every other language still comes from the
  host, and the missing-dictionary state already works visibly.
- Transitive Rust-crate and transitive npm-module texts remain M6-10 work
  (limitations L2/L3); direct runtime texts are retained.
- Regenerating notices requires the Arch build host (pacman provenance);
  recorded in the tool. A release rebuild must rerun
  `tools/build-package-notices.py` and commit the result.
