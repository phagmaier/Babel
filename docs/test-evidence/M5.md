## M5-01 — Bundled offline renderer helper

Date: 2026-10-02 PDT. One editing agent on `main`, base `7552b02`. Owner
delegated the packaging choice. Host: Linux 7.2.7-arch1-1 x86_64, Python 3.14
(build host), Rust 1.97.1, Node 26.7.0, pnpm 11.22.0, Poppler 26.08.0. Decision:
[ADR 0036](../decisions/0036-bundled-pdf-helper.md); tooling `tools/pdf-helper/`.
Logs in `target/m5-01/`.

- Pinned inputs fetched and checked with `sha256sum -c` — **passed** for the
  CPython 3.13.16+20261001 `install_only_stripped` tarball and four wheels
  (Screenplain, ReportLab, charset-normalizer, Pillow 12.3.0, later dropped).
- Linkage probe: `ldd`/`readelf` show `bin/python3.13` needs only glibc
  (statically linked `libpython`), so the 32 MB shared library, Tcl/Tk, headers
  and terminfo were dropped. `sys.builtin_module_names` confirms OpenSSL 3.5.9,
  editline (BSD readline backend), ncurses 6.5, SQLite 3.53.1, expat 2.8.5,
  mpdecimal 4.0.0 and zlib 1.3.2 are built in. They are recorded with expected
  licenses; full texts remain M6.
- Pillow probe: without Pillow, ReportLab **failed to import**
  (`reportlab/lib/utils.py` imports `PIL.Image`). With real Pillow and with the
  refusing stub, the four M1 corpus PDFs are **byte-identical** (`cmp`), so
  Pillow and its vendored native libraries are not bundled.
- `python3 tools/pdf-helper/build.py --offline` — **passed**, ~3.4 s, 1,473 files,
  60,623,213 bytes, tree `7f1fdf6828596d43097816a61cbabc7a638eb4680da3a98b636020a095ad29a0`.
  Repeat builds give the same tree hash. One rebuild produced `55832e8b…`
  because a local `py_compile` check had left host bytecode in `stubs/`. The
  build now ignores `__pycache__`, and the hash is stable with or without stray caches.
- `python3 tools/pdf-helper/test_helper.py` — first run **failed 6/9**:
  replacing `socket.socket` with a function broke `ssl`'s subclass, and
  unexpected errors escaped as tracebacks. Fixed by disabling socket methods and
  mapping unexpected errors to `internal`. Then the test's sealed `PATH` hid
  `unshare` (test bug, fixed with an absolute path). Final **11/11 passed**:
  M1 corpus 2/6/3/2 Letter pages (`pdfinfo`) with Courier Prime embedded
  (`pdffonts`), scene-heading order (`pdftotext`), byte determinism, BOM/CRLF
  equivalence, offline `unshare --user --net`, Pillow stub refusal, seven
  request refusals, no overwrite of an existing or symlinked output, invalid
  UTF-8/oversize leave no output, changed font refused. HOME, TMPDIR, cwd and
  the runtime tree are unchanged after all runs. Median 131 ms per helper call
  (background measurement, not a typing-path claim).
- `pnpm tauri build` (helper via `beforeBuildCommand`) — **passed**, AppImage
  118.94 MiB versus 99.44 MiB with an empty helper directory (+19.5 MiB). App
  binary unchanged, SHA256 `0f4ba9bb…fe130d`. AppImage bytes differ between
  builds (packager timestamps); the helper tree does not.
- First packaged check found **27 changed files**: linuxdeploy rewrites the
  loader metadata of every ELF under `usr/lib`. Dropping Pillow left one ELF.
  `python3 tools/pdf-helper/verify_runtime.py <extracted>/usr/lib/babel/pdf-helper`
  — **passed**: tree `7f1fdf68…`, only `python/bin/python3.13` metadata patched,
  with `.text`/`.rodata`/`.data`/`.init`/`.fini` identical.
  `BABEL_PDF_HELPER_RUNTIME=<extracted> python3 tools/pdf-helper/test_helper.py`
  — **11/11 passed** from the packaged copy (median 202 ms).
- Fresh-checkout case: with no runtime built, `cargo check -p babel-desktop --locked`
  — **passed**; `build.rs` created the empty resource directory.
- Shared gates (`RUSTUP_TOOLCHAIN=1.97.1`, `mise exec node@26.7.0 pnpm@11.22.0 --`):
  `cargo fmt --all --check`, `cargo clippy --workspace --all-targets --locked -- -D warnings`,
  `cargo test --workspace --locked` (**237 passed**), `pnpm format:check`,
  `pnpm lint`, `pnpm typecheck`, `pnpm test` (**695 passed, 56 files**),
  `pnpm build`, and `python3 -m py_compile` on the helper sources — **all passed**.
  `pnpm test:browser` omitted (no frontend/DOM change).
