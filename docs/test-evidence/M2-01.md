operations: BOM/CRLF/meaningful whitespace/unknown syntax/empty source exact
bytes and no-op source mtime/mode preservation; independently known `abc`

persistent loose identity across restart/replacement and independent copies;
corrupt/future registry preservation; managed/unknown-field metadata;

managed mapping candidate; same-process and independent-process contention;
duplicate managed UUIDs; revoked/forged/cross-session handles; unsaved identity
and capacity bound; edit/replace/delete/chmod/symlink divergence; moved source
parent/store and replaced lock inode; changed managed identity. The immutable
initial source remains available after external divergence.

The child-process test execs the compiled test binary with `PATH=/nonexistent`
and confirms the parent lease still owns the synthetic source. The
`ownership_child` harness entry is a no-op during the ordinary suite; its
assertions run in that explicit child invocation.

`src-tauri/src/document_ipc_tests.rs` dispatches through **Tauri MockRuntime**:
exact raw bytes, typed errors, cross-session rejection, extra-path rejection,
no write/open-by-path command, revocation, and honest uninitialized production
state. This is IPC contract evidence, not native WebView E2E.
`tests/contract/document-ipc.test.ts` mocks `invoke` to verify frontend
identity-only forwarding, raw byte retention and failure propagation.

### Corrections and limits

Initial `cargo test -p babel-desktop --locked` correctly refused the changed
dev-dependency lock; rerunning without `--locked` updated Cargo.lock. All final
checks use the resulting lock. Initial Clippy failed on a test's non-octal
permission literal; corrected to `0o0`. Initial `pnpm check` and `pnpm test` failed on two
frontend failure tests because `beforeEach(() => invoke.mockReset())` returned
the mock as a cleanup function, calling it again after each test. Context7
confirmed the cleanup contract; the hook now uses a block without returning
the mock. The original-object rejection assertions remain. These were failed checks,
not passes; final reruns are recorded above.

No source save, journal/checkpoint, recovery-available status, editor, parser,
history/remote integration or PDF operation is added. Native selection UI and
real WebView manuscript opening remain unwired. ACL/xattr ownership policy,
foreign-owner fixtures (without privilege), network/external/sync filesystems,
hardware power loss and other platforms are unverified. Btrfs/tmpfs results
only close the bounded Linux M2-01 task, not M2 exit or product adoption.
M2-02 is next after review.
