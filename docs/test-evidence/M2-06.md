## M2-06 — Small history primitives and safety gate

Date: 2026-09-28 PDT. Main base `7ea1355`, clean starting tree. Host:
Linux 7.2.5-3-omarchy x86_64, Rust 1.97.1, Node 26.7.0, pnpm 11.22.0;
`/tmp` is tmpfs and the workspace is Btrfs. Only private random synthetic
fixtures were used. No real manuscript, credential, system Git executable,
provider, remote, global setting or privileged package was used.

### Acceptance and safety observations

- Native `screenwriter-core` owns private bare per-document Git repositories and
  an identity marker. A curated tree contains exactly raw `screenplay.fountain`
  and a portable project/source/profile-hash manifest. It uses an app-local
  signature, no user/system Git configuration, and no shell command or network
  transport. Explicit revisions require exact owned disk bytes or the latest
  exact current-session checkpoint. Changed profile/content makes a first-parent
  commit; unchanged content deduplicates. Main publication is checked; safety
  refs are verified. Tests independently inspect Git trees/blobs/parents/refs,
  including BOM/CRLF, trailing spaces and unknown Fountain text.
- Five in-crate native tests cover curated bytes/dedup/profile, managed project
  profile, forged/unprotected content rejection, interrupted object and
  main/safety-ref publication/retry, corrupt ref preservation, ordinary
  source/recovery isolation, and restart attention. The no-Git-PATH run
  exercises these five tests using the compiled native test binary.
- A recovery-choice integration test proves a successful adoption first
  publishes a safety ref whose curated source is the former disk generation.
  Another corrupts the history ref, observes `HistoryNeedsAttention` and no
  destructive adoption, retains the old source/new recovery, then makes an
  ordinary source save with the corrupt history untouched. Snapshot restore
  uses the same pre-replacement safety operation; its existing success and
  failure suites are included in both full runs.
- `m2_exit.rs` uses one synthetic source for exact open/save/reopen, a newer
  acknowledged recovery checkpoint, explicit adoption as a newer source
  version, retained previous source and healthy safety history. Full workspace
  runs repeat earlier source/recovery/snapshot replacement fault, SIGKILL,
  version-race, lease and MockRuntime contract suites on both filesystems.
  The M2 headless Linux exit passes within this bounded coverage.

### Limits and next action

picker, cadence and Save As. This is a native headless testable API, not a
Local-v1 writing workflow. History ref/object power-loss durability and
multi-ref atomicity, actual disk-full/hardware crash, physical-disk
independence, other OS adapters and installed/offline use remain unverified.
M1 local bare-remote proof is separate; no M7 transport/privacy gate is
claimed. Continue with **M3-00 decomposition** after this M2 boundary.
