## What changed

Exact licence texts and provenance for every library the AppImage actually
bundles, derived from the artifact itself (`--appimage-extract`), recorded
under `docs/third-party/` in the existing table style, plus a notice file
inside the package, in-app surfacing and a build/CI gate.

- `tools/build-package-notices.py` (new): inventories every ELF, provider
  module and font in the AppDir, maps each to its Arch provider via pacman,
  retains verbatim texts under `docs/third-party/package-licenses/` (138
  texts) and generates `package-inventory.json`, `package-libraries.md`
  (141 entries) and `NOTICES.md`.
- `tools/check-package-notices.py` (new): fails the build when a bundled
  library/module/font has no retained text, a text is missing, the
  in-package notice is absent or the pdf-helper pins changed. Coverage-only,
  so the Arch-authored manifest also gates Ubuntu CI. Wired into
  `.github/workflows/check.yml` after the spellcheck check and into
  `docs/development.md` + the native guide.
- In-package notice `usr/lib/babel/THIRD-PARTY-NOTICES.md` (Tauri resource,
  byte-identical to the committed source) and a read-only path to it: narrow
  `third_party_notices` IPC command, `Tools → Third-party notices` catalog
  entry (palette + native menu), lazy dialog from Home and the writing view.
- Inventoried artifact: `babel_0.0.1_amd64.AppImage`
  SHA-256 `38710fb1cba4622bc0b744ed8891a2d23f3e6045322279cac3feaa30759a805e`;
  fresh `--appimage-extract` is byte-identical to the build AppDir.
