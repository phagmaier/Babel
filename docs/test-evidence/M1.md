## M1-01 — loss-aware Fountain/editor contract

Artifacts: [fixture manifest](../../fixtures/fountain/README.md), four original synthetic byte fixtures, [disposable codec](../../prototypes/fountain/codec.ts), [focused tests](../../tests/contract/fountain.test.ts), [ADR 0007](../decisions/0007-source-aware-fountain-contract.md). No application editor or save path is connected to the prototype.

Observed acceptance:

- All four sources return exact no-op bytes, including UTF-8 BOM/CRLF/no final newline and an invalid UTF-8 source. The latter has an exact source copy and a read-only reason.
- The supported model recognizes selected title fields and continuations, headings/scene number, action, cue/extension, dialogue and parenthetical, a dual relationship, lyrics, centered text, transition, section/synopsis, page break, notes, boneyard, inline marker text, and intentional two-space dialogue separators. Expected kinds and values are asserted manually in the focused test.
- Selected one-line action, forced heading, and character edits reparse to the requested semantics. An action edit leaves preceding source bytes, BOM/CRLF, missing final newline, blank lines, title/dual/omission content intact. A numbered scene retains its number. A bounded six-value Unicode/action loop supplements the named fixtures.
- A raw extension rejects structured edits, an incomplete cue produces a diagnostic, and conversions that would change a neighboring dialogue/dual interpretation reject the edit. [ADR 0007](../decisions/0007-source-aware-fountain-contract.md) records the unproved grammar and editor cases.
