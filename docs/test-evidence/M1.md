## M1-01 — loss-aware Fountain/editor contract

Artifacts: [fixture manifest](../../fixtures/fountain/README.md), four original synthetic byte fixtures, [disposable codec](../../prototypes/fountain/codec.ts), [focused tests](../../tests/contract/fountain.test.ts), [ADR 0007](../decisions/0007-source-aware-fountain-contract.md). No application editor or save path is connected to the prototype.

Observed acceptance:

- All four sources return exact no-op bytes, including UTF-8 BOM/CRLF/no final newline and an invalid UTF-8 source. The latter has an exact source copy and a read-only reason.
- The supported model recognizes selected title fields and continuations, headings/scene number, action, cue/extension, dialogue and parenthetical, a dual relationship, lyrics, centered text, transition, section/synopsis, page break, notes, boneyard, inline marker text, and intentional two-space dialogue separators. Expected kinds and values are asserted manually in the focused test.
- Selected one-line action, forced heading, and character edits reparse to the requested semantics. An action edit leaves preceding source bytes, BOM/CRLF, missing final newline, blank lines, title/dual/omission content intact. A numbered scene retains its number. A bounded six-value Unicode/action loop supplements the named fixtures.
- A raw extension rejects structured edits, an incomplete cue produces a diagnostic, and conversions that would change a neighboring dialogue/dual interpretation reject the edit. [ADR 0007](../decisions/0007-source-aware-fountain-contract.md) records the unproved grammar and editor cases.

## M1-02 — native ProseMirror input proof

Host: same Omarchy/Linux x86_64 machine, AMD Ryzen 7 7840U (8 cores/16 threads), 14 GiB RAM, WebKitGTK 4.1 2.52.6, GTK 3.24.52, Hyprland 0.56.2, Wayland/XWayland. Tauri debug build with explicit `native-editor-proof` feature, Vite dev server, 545×702 logical window. Local date: 2026-09-27 PDT. The proof page and native report command are isolated from the production route; no manuscript or save path was involved. See [proof instructions](../../prototypes/native-editor/README.md) and [ADR 0008](../decisions/0008-native-editor-input.md).

This is a native WebKit key-to-frame proxy; it does **not** measure final compositor presentation or prove all sessions stay below the SPEC S13 targets. The 600 workload visibly kept the caret and edited tail on screen in the inspected native screenshot `/tmp/babel-m1-proof-600.png`. The WebView report identified `nativeHost: true` and matched all three Node-computed fixture hashes.

Behavior observed in the 120 workload using real Wayland virtual keyboard/clipboard input:

- Paced typing appended all 31 characters of ` Native input proof 0123456789.` as 31 `beforeinput:insertText` events and 31 document changes. ProseMirror and DOM caret positions agreed at the end.
- `Shift+Home` selected ProseMirror positions 233737–233793 and the same 56-character DOM text. Ctrl+Z restored the original tail in one history action; Ctrl+Shift+Z restored the typed phrase.
- A live `wl-copy --foreground` source plus Ctrl+V produced a native paste event carrying ` PASTE sentinel`, appended exactly that text, and Ctrl+Z removed it. An earlier `wl-copy` attempt whose source process exited produced an empty paste; the foreground source corrected the test setup.
- `wtype -k dead_acute -k e` produced actual WebKit compositionstart/update/end and `insertCompositionText`, `deleteCompositionText`, `insertFromComposition`, yielding `é`. `dead_acute` then Return committed `´` and generated `insertParagraph`. In the event trace, `compositionend` preceded `keydown:Enter:composing=false` for that same key sequence. A smart Enter implementation must account for this ordering; relying only on `KeyboardEvent.isComposing` would be insufficient here. No smart Enter handler was added or product Enter rule changed in this proof.

Representative exact native input commands (the proof window was focused with `hyprctl dispatch 'hl.dsp.focus({ window = "class:babel-desktop" })'`; `F10` cycled the three workloads):

```sh

wtype -k F7 -M shift -k Home -m shift -k F8

```
