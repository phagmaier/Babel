## M1-01 — loss-aware Fountain/editor contract

Artifacts: [fixture manifest](../../fixtures/fountain/README.md), four original synthetic byte fixtures, [disposable codec](https://github.com/phagmaier/Babel/blob/fb7d6bd5bf034458afd950d5f9632382b6d5b99b/prototypes/fountain/codec.ts), [focused tests](https://github.com/phagmaier/Babel/blob/fb7d6bd5bf034458afd950d5f9632382b6d5b99b/tests/contract/fountain.test.ts), [ADR 0007](../decisions/0007-source-aware-fountain-contract.md). Observed acceptance:

An action edit leaves preceding source bytes, BOM/CRLF, missing final newline, blank lines, title/dual/omission content intact. A numbered scene retains its number. A bounded six-value Unicode/action loop supplements the named fixtures.
- A raw extension rejects structured edits, an incomplete cue produces a diagnostic, and conversions that would change a neighboring dialogue/dual interpretation reject the edit. [ADR 0007](../decisions/0007-source-aware-fountain-contract.md) records the unproved grammar and editor cases.

## M1-04 — durable replacement proof

Host: Omarchy/Linux 7.2.5-3-omarchy x86_64, unprivileged user, Rust
1.97.1; local date 2026-09-27 PDT. Branch: `M1-04-durable-replacement-proof`.
Authority: SPEC S10/S15, SAVE-01–03, INV-04/05. Decision:
[ADR 0010](../decisions/0010-linux-durable-replacement.md);
[harness](https://github.com/phagmaier/Babel/blob/fb7d6bd5bf034458afd950d5f9632382b6d5b99b/prototypes/durable-replacement/README.md).
No app linkage, manuscript input, IPC, third-party dependency or production
checkpoint/save implementation. `Cargo.lock` only adds the local proof crate.
`findmnt -T /tmp -no FSTYPE,TARGET` reports tmpfs;
`findmnt -T . -no FSTYPE,TARGET` reports Btrfs on the host workspace.

Thirteen tests exercise real disposable native operations plus deterministic
error hooks. Thirty injected permission/other errors across 15 boundaries
never return a receipt. Three injected ENOSPC errors cover recovery, prior
copy and candidate writes (no actual disk filling). Short writes complete;
partial ENOSPC and falsely successful truncated writes preserve old source,
old independent copy and new recovery; verification rejects the candidate.
Native 0500-directory permission denial and rename-over-directory failure
are observed, with safety copies retained. Exclusive creation refuses
leftovers and symlink targets; read-only, symlink and hardlinked source
inputs are rejected. External byte/inode/mode changes and move/removal
stop replacement at recheck and preserve all available generations.

Fifteen children are SIGKILLed at pipe barriers before each operation:
from before recovery creation through after rename and final directory
sync. Fresh reads after process exit see exact whole OLD before rename or
NEW after rename, never torn current source; post-rename cases retain OLD
previous + NEW recovery. No child emits ACK. A killed worker releases its
lock, and a separate successful child emits exact `ACK 21 75` only after
sync/verification (source length is asserted from the independent literal).
Tests preserve original BOM/CRLF and meaningful spaces by exact comparison;
source mode remains 0640, safety copies 0600, private directory 0700.
Safety copies remain unchanged after external current-file mutation.

A competing child cannot acquire a cooperating writer lock. Initial command
`CARGO_HOME=/tmp/babel-cargo cargo test -p durable-replacement-proof` failed
1/11 tests: lock reacquisition in the parallel suite reported WouldBlock,
while the isolated test passed. Explicit unlock was added to owned leases
and test lock release, rather than weakening/serializing tests. Final suite
passes both filesystems and ten consecutive normal parallel tmpfs runs
(130 test executions), logs below. The inherited-descriptor explanation is
a source-informed inference; exact kernel scheduling was not traced.

The counterexample test changes current bytes between recheck and rename:
replacement succeeds and racing external bytes are overwritten. This
explicit residual limitation matches SPEC S10.4; no universal-lock claim.
Post-rename injected sync/verification errors report replaced=true with no
receipt; recovery and previous generation remain. SIGKILL is process-loss
evidence, not power-loss evidence; tmpfs has no reboot durability.

Platform/power-loss, secure handle-relative path operations, ownership/ACL/
xattr/special-mode policy, framed recovery and prior-checkpoint retention,
session/version races, hashes/bounds, queue/restart classification and real
UI failure states remain M2/M6 work. No M1-04 blocker remains on the tested
Linux host; other platforms are unverified, not failed or passed.

## M1-06 — Bounded codec/editor/native composition proof

Date: 2026-09-28 PDT. Single editing agent on main; implementation base `d64f3ab` contains accepted writer `5e84879`. Clean starting tree, no prior dirty paths. ### Reviewed bounded conclusion

**Pass for the declared text-edit subset on this host.** One typed ProseMirror EditorState composes the existing M1 codec with the existing native controller/writer through no-op save, Unicode typing, selection replacement, undo/redo, exact save receipts and native reopen. Current source ranges and UTF-16/UTF-8 caret anchors agree with independently authored expected bytes. Protected blank/raw regions, scene-number source, cue/dialogue interpretation, BOM, CRLF and missing final newline survive. Undo restores exact original bytes/selection and advances the version; the later restored edited content is saved at v16 rather than reusing its earlier version. Native external divergence refuses replacement while keeping exact external bytes and independently checksum-verified local recovery on both filesystems.

The single editing agent reviewed the implementation, literal fixture oracles, native outputs and final boundary diff. This is not a new independent agent code-review claim. M1-06 closes its bounded investigation; production M3/full M2 exit and Local v1 requirements remain open. M2-05C was not started.

The original source snapshot is immutable plugin data in the sole EditorState, not a writable peer authoring buffer. Typed line nodes retain stable session IDs; capture derives source and current ranges from their text. The diagnostic refuses structural/type/ID/protected-region transformations, ambiguous reparses, invalid Unicode and multiline paste. Its synchronous transaction grammar filter is explicitly bounded to 1–32 lines/4 KiB; hashing/capture/native work execute outside input handlers. This does not prove a production incremental codec, large-document responsiveness, full Fountain/renderer conformance, structural undo, IME, transient empty drafting intent, reopen selection restoration, power loss, other platforms or installed-package adoption. Earlier-session recovery is never bypassed to continue writing after reopen.
