## Deliverable

Distinct Export Fountain copy versus Save As active project/independent duplicate, with explicit identity semantics and exact version receipt.

## Acceptance criteria

- New duplicate identity has no inherited remote link
- Source/profile/metadata publication is restart-safe, uses native destination authority and preserves prior source/recovery/ownership until success
- Existing destination is refused or separately reviewed/protected before overwrite; no implicit overwrite
- Cancellation, read-only/unsaved origins, metadata/lease collision, partial writes, sync failure, transport loss and interruption cannot falsely switch the active identity or lose generations
