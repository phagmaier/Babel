## Acceptance

- Receipt binds operation kind, identity/session, version, source hash/length and verified safety ref. Protection freezes/captures the precise live version; after await, document/version/selection are rechecked before a separately owned editor transaction can run.
- Define the move-size threshold in the workflow contract before enabling moves. Large operations require confirmed recovery and safety revision; cancel, failed protection, stale receipt, composition or uncapturable draft leaves editor/source untouched with an actionable message.
- History failure refuses the requested destructive operation while ordinary writing, raw recovery, source Save and emergency copy remain available. Checkpoint/history receipts never mark source saved. No arbitrary action label/path or source interpretation is delegated to Rust.
- Bound worker jobs/payloads; strict IPC rejects forged/cross-session/extra-field requests. Interrupted safety publication preserves previous refs/checkpoints; no cleanup of the only protected draft.
