## Verification policy for M4 implementation tasks

Each brief's focused command is **planned** until its named test exists. It supplements [required shared checks](../../development.md#commands): `pnpm check`, `pnpm test:browser`, `cargo fmt --all -- --check`, `CARGO_HOME=/tmp/babel-cargo cargo clippy --workspace --all-targets --locked -- -D warnings`, and `CARGO_HOME=/tmp/babel-cargo cargo test --workspace --locked`. Build/review the default release with `CARGO_HOME=/tmp/babel-cargo pnpm tauri build --no-bundle` for native behavior; dependency/resource/packaging changes also require `pnpm tauri build`. Never substitute a proof-feature app for production verification.

For native filesystem changes run the workspace suite on both the actual tmpfs and Btrfs synthetic roots using the existing [development matrix](../../development.md#task-specific-focused-checks). Include real UI/restart/fault drills on both filesystems when publication, identity, leases, recovery or history are affected. Pure indexes/rules/codec/state transformations need no duplicate filesystem run. Each task records applicability/omissions.

UI tasks need actual default-app keyboard/pointer/focus/IME inspection of changed behavior. Extend the existing [native lifecycle harness](../../../tests/native/writing-lifecycle/README.md) with task-scoped synthetic cases, documenting the exact invocation in development/evidence when it exists. Browser/JSDOM/MockRuntime results retain their labels. Record failures, independent exact-byte/selection oracles, fixed fixture sizes/hashes and measurement limits in [M4 evidence](../../test-evidence/M4.md). Finish with `git diff --check`.

Tasks own their named modules and focused tests; the single editing agent also updates the owning subsystem doc and task status. `TODO.md`, trace, state, index, ADRs and evidence remain coordinator-owned if concurrency is later requested. Shared editor/lifecycle integration paths require sequential work. Lasting platform/dependency/ownership decisions need an ADR at implementation, rather than speculative ADRs in this decomposition.
