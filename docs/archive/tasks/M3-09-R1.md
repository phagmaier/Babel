## Owned paths and deliverable

owning docs; coordinator owns task/status/trace. Provide an explicit route from a
selected unsaved checkpoint to an editable recoverable draft or exact standalone
copy in the default app. A new identity is acceptable when explicitly described;
the original recovery remains intact and unrelated active work is protected.

## Acceptance

- New, type, acknowledge checkpoint, owned SIGKILL, restart, select checkpoint,
  resume/export, save, close and reopen uses ordinary default-app controls.
- Full bytes come from a revalidated exact candidate, never a truncated preview
  or manual reconstruction. Preserve unknown/invalid content conservatively.
- New draft protection/version/hash is verified before claiming recovery;
  old checkpoint is preserved through cancellation, stale selection, transport,
  protection, destination and adoption failure. No timestamp content winner.
- No arbitrary path/shell IPC; stale results cannot overwrite another editor.
- Shared checks plus tmpfs/Btrfs native restart/entry/copy/publication checks,
  including a checkpoint larger than the UI preview limit. Update M3 evidence.
