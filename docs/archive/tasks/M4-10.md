## Own and deliver

Scoped app/editor styles, bounded versioned UI preferences and theme/zoom/focus/typewriter controls, related registry availability and planned preference/UI tests. Keep the writing screen restrained and errors persistent.

## Acceptance

- Light/dark, readable bounded zoom, focus mode and typewriter scroll work without rebuilding EditorState, changing authored bytes/selection or export typography. Focus mode retains a discoverable exit and visible save/recovery failures.
- Preferences contain UI configuration only; validate schema/ranges, show storage failures honestly and retain prior working settings. Keyboard/focus/cancel behavior and reduced motion/contrast/non-color statuses are consistent across home/writing/panels.
- Typewriter follows caret only when intended; does not fight manual scrolling, composition, search/outline jumps or dialogs. Zoom/high-DPI preserves caret/popup alignment. No fabricated page markers/counts.
- Record native input/IME/selection and synchronous work while toggling modes/zoom on typical/stress synthetic scripts; address regressions without claiming full S13 compositor/long-session acceptance.
