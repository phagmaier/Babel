## Owned paths and deliverable

The editor capture/session/close/status boundary, its narrow native copy contract
if needed, owning docs and focused tests. Coordinator owns task/status/trace.
Expose truthful protection facts immediately for every live editor version,
including failed/pending captures, and a usable preservation route for accepted
drafts that cannot round-trip as Fountain. Choose and document a bounded artifact
format if the copy must carry live rows/styles plus original source bytes.

## Acceptance

- The native R03 middle-Parenthetical split shows newer work only in memory;
  old source/recovery receipts cannot label that live draft saved or protected.
- Pending/stale/failed hashing or capture cannot regress live status or authorize
  close against an earlier version. No serialization/hash on a synchronous key.
- An explicit native-selected copy preserves all latest row text/styles and exact
  original source independently; it is accurately labeled and never called a
  successful latest Fountain save. Failure retains editor and original source.
- Copy receipts, close/risk decisions and concurrent edits bind exact versions;
  Undo remains coherent. Native read-only/protected regions keep their guards.
- Regression covers capture failure, older completion/receipt, copy failure,
  cancellation, editing during failure, retry/Undo, and close after verified copy.
- Shared checks and default-app capture/close/copy drill on tmpfs/Btrfs, with
  independent source/live-artifact/selection audits. Update M3 evidence and trace.

## Boundary

parenthetical rows, broaden filesystem privileges, or mark M3-13 accepted.
