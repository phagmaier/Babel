# M6-01-R1 Retained shutdown disposition or supported-runtime follow-up

Status: **ready for bounded artifact/disposition review; runtime trial blocked until a supported candidate is verified**
Dependencies: M6-01 review/evidence and current Linux scope; a runtime-change arm additionally requires a supported corrected candidate and authorization for that change
Requirements: SAVE-05, QA-01/02, SEC-02; preserve INV-04/05/06/10/18

## Trigger and scope

C1 parent SIGKILL and F2 active WebDriver DELETE bypass the accepted-close
mitigation. M6-01 retains both findings and keeps release gate C open; new clean
samples cannot erase historical failures. Read [M6-01](M6-01.md),
[ADR 0035](../../decisions/0035-linux-web-process-close.md) and
[M6 evidence](../../test-evidence/M6.md).

Select one arm before work: (A) review retained artifacts and reachability for
an explicit residual-risk decision under the
[native policy](../../native-findings.md#disposition-and-escalation), or (B) verify
and trial one supported corrected runtime. Arm A needs no runtime upgrade and
cannot call clean controls a repair. Record ordinary-operation/IME readiness
failures separately from forced teardown; keep unknown phase unknown.

For arm B, verify the supported runtime's release/packaging and
patch inclusion from primary sources and actual mapped binary identities.
An upstream fixed bug alone is insufficient. Freeze old/current binaries and
one candidate, one supported mitigation at a time. Do not begin a private
WebKit distribution, broad graphics bisection or system package installation.
A necessary application/dependency correction gets a narrowed scope addendum
with demonstrated reachability before coding.

## Acceptance and checks

Arm A: inspect original C1/F2 ledgers, failed manifests and independent source/
recovery audits; name trigger, build/runtime, reachability, protection limits
and remaining risk. End with explicit reviewed acceptance or a concrete narrowed
follow-up. Fresh reproduction runs only when the stated question needs it.
Artifact review needs Tier 1 checks; it closes no code/runtime verification gate.

Arm B: repeat SHUTDOWN-RETAINED ordinary/restart, C1 kill/recovery and F2 forced DELETE
on tmpfs/Btrfs with the matched non-WebDriver control, owned PID/start tokens,
bounded stderr/kernel/coredump scans and independent current/source/previous/
acknowledged-recovery byte audits. Preserve failed roots and all core identities.
Record mapped stack hashes, missing symbols, workload omissions and exact phases.
Run affected Tier 3 local checks from M6-00 for any code/runtime change; packaging
changes also require actual installed/offline checks before release admission.

A reviewed disposition must explicitly name C1 and F2 and its limits. Neither
ordinary close nor intact bytes nor a non-reproducing control resolves them.
Until supported correction or explicit release review is verified, keep C open
before M6-14/16. Independent M6-02 safety work may proceed from the M6-01 review.

## Excludes and stopping

No history workflows, unrelated upgrades/refactors, private engine shipping,
crash suppression, forced system updates, global settings or milestone admission.
Stop after one artifact/disposition review or one supported candidate/control.
Further trials need a concrete new question. Missing runtime availability blocks
arm B only; missing identity/native proof remains an explicit verification gap.
No deadline or inconclusive control grants release acceptance.
