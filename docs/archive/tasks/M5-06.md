## Own and deliver

An Export PDF command (palette/menu/shortcut registry), native destination
selection with no frontend path authority, and atomic publication of the PDF.
Export captures the current text after a safe checkpoint, renders it through
the same M5-02 pipeline as the preview, and reports exactly which version was
exported.

## Acceptance

- Blocking SC005/SC008 limitations require an explicit, informed user decision
  before any PDF is written. A strict export profile may require acknowledging
  structural warnings, but never blocks saving the source. An `unavailable`
  assessment never yields "export succeeded".
- The destination is written by atomic replacement. Export refuses to overwrite
  the manuscript, its recovery/history files, or any open document's source.
  Failures leave source, recovery and the previous destination intact.
- If typing continues during export, the result still names the captured
  version. A cancelled export writes nothing.
- No network, no shell. The PDF contains only the captured source's content.
