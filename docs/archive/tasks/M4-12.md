## Own and deliver

Selected spellcheck adapter/controller, editor advisory/correction integration and language/ignore/add controls; native typed commands/resources only if the accepted proof needs them. Focused contract/UI/native dictionary tests and exact license/packaging records.

## Acceptance

- Offline language selection, suggestions, per-session Ignore and explicit local Add work in the default app; scope/persistence is clearly explained. Established screenplay names are handled by documented local vocabulary rules without automatic dictionary pollution.
- Corrections are explicit coherent editor transactions preserving source/marks/caret with one Undo step. Composition/read-only/protected regions/stale suggestions respect existing guards. Dictionary failure never blocks writing/saving/recovery and does not mutate manuscript bytes.
- Validate/bound language/word/preferences/queues, reject hostile entries and retain prior valid dictionary on failed/interrupted persistence. No general path endpoint/cloud lookup or source logging; resource absence has a visible usable fallback state.
- Verify default release resolves exact offline resources without Vite or network. This resource check does not establish M6 installed/offline adoption or other OS support.

## Verification

- Planned `pnpm exec vitest run tests/contract/spellcheck.test.ts tests/ui/Spellcheck.test.tsx`; M4-00 shared/native build checks and `pnpm tauri build` if resources/dependencies change.
- Actual native language/suggestions/name/ignore/add/restart/Undo/IME and no-egress inspection. tmpfs/Btrfs required if custom native dictionary metadata publication exists; otherwise record reliance on the verified platform implementation. Evidence: [M4](../../test-evidence/M4.md).

## Excludes

Automatic rewriting, online grammar, global personal dictionary modification, broader platform packaging and owner adoption.
