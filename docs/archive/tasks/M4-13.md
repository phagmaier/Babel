## Own and deliver

Versioned character/count projections, character list/focus decorations, safe auxiliary last-position storage/routing and planned character/count/position contract/UI tests. Extend native registry storage narrowly only if needed; document its failure isolation.

## Acceptance

- Character list/optional dialogue highlighting and navigation distinguish names/extensions/Unicode according to documented vocabulary rules; never change authored cue spelling. Counts state inclusion rules for words/scenes/characters/title/notes/omissions/raw text and show stale/unavailable facts when necessary. No guessed page count.
- Restore caret/scroll using bounded source-hash/identity-validated anchors, not durable session IDs alone. External edits/Save As/missing files/recovery/restore use a safe fallback rather than arbitrary offsets; exact checkpoint selection takes precedence over old recent-position hints.
- Auxiliary position/preference failure/corruption does not gate source saving/close, overwrite recovery metadata or earn protection credit. Store only required local UI data, with no full manuscript mirror/logs. Publication uses the M4-01 safety policy if native storage changes.
- Character/count/index work is coalesced/bounded; navigation/typing/IME and manual scroll remain accurate under theme/zoom/typewriter. View changes never alter source/version.

## Verification

- Planned `pnpm exec vitest run tests/contract/character-counts.test.ts tests/contract/recent-position.test.ts tests/ui/CharacterPanel.test.tsx`; independent inclusion/Unicode/anchor/stale oracles and M4-00 shared checks.
- Native highlight/navigate/close/reopen/changed-source/recovery precedence/Save As inspection. tmpfs/Btrfs required for any new native position metadata publication; pure counts need no second run. Evidence: [M4](../../test-evidence/M4.md).

## Excludes

Page counts, richer statistics, history diff, using auxiliary state as authored content and long-session performance certification.
