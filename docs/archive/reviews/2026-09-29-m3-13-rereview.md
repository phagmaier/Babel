## C1 — Recurring WebKit child heap abort at forced shutdown

Category: **reliability / native-runtime investigation**. Severity: **Medium**
for the observed forced-shutdown scenario. Confidence: **High** for recurrence,
**Medium** for association with graphics teardown, **Low** for the corruption's
origin or impact outside this scenario. Components: host WebKitGTK 4.1 2.52.6,
Mesa Gallium/EGL 26.2.2-arch1.1 and the owned-process termination drill in
`tests/native/writing-lifecycle/drill.py`; no repository fault is established.

Evidence: PID 779415, owned synthetic Btrfs profile, SIGABRT at 19:45:23 PDT.
The source-failure screenshot and new-session metadata bracket the deliberate
parent SIGKILL in that same second. WebDriver stderr says
`free(): corrupted unsorted chunks`. The all-thread core shows an allocator
abort on the thread named `WebKitWebP:sh3`, a main thread exiting through Gallium, and
another thread in WebKit/EGL thread-local destructors. This follows the earlier
owned WebKit exit abort recorded with the corrections. Memory was available and
the kernel journal shows no OOM event. Internal driver frames are incomplete;
the evidence does not identify who corrupted the heap or establish a link to
the GLib advisory. Exact commands/logs and symbol-fetch limits live in
[evidence](../../test-evidence/M3.md#recurrent-owned-webkit-teardown-abort).

Why it matters: the repeat confirms runtime instability and produces a crash
notification/core during a supported recovery drill. Ordinary editing or
normal-close impact remains unknown. No synthetic author bytes were lost:
the acknowledged checkpoint was verified before kill, restart recovered its
exact bytes, and the remaining source/copy/close checks completed successfully.

Recommended next step: isolate forced and ordinary shutdown on a supported
native-stack combination in a disposable environment, obtain complete
allocator/driver symbols, and identify a supported upstream fix or justified
app lifecycle correction. Do not infer an exploitable vulnerability, blame a
specific dependency, disable graphics globally or ship an unverified workaround.
Validate any fix with repeated owned close/SIGKILL/restart cycles, absence of
heap errors/new cores, and the existing exact-byte recovery/failure matrix before
the installed/offline pilot. This is open hardening work, not a corrected defect.

## Cross-subsystem review and sound paths

- **One live authority and exact status:** `WritingView` owns EditorState;
  `EditorCaptureBoundary` produces owned, version/session-checked derivatives.
  `WritingSession` reads the actual editor version for pending/close facts.
  Controller receipts match identity, version, hash and length; old receipts
  cannot protect newer authoring or selection versions. A failed capture is
  deliberately conservative, rather than a reason to reuse an old saved label.
- **Identity transitions:** Save As compares every published byte and its native
  fingerprint before adoption. The original immutable editor state and stack
  survive adoption/release failure. Successful adoption retires the previous
  cadence; failed initial opens release their native registrations. Native
  destination capabilities remain identity-scoped and path-free.
- **Replacement and recovery:** `replaceFromNative` freezes the editor, drains
  pending work and independently protects the live draft. The view prepares
  replacement source-bound metadata before calling native restore/recovery;
  native payload bounds are checked before destructive work. Hash-verified
  sparse intent/caret metadata rejects stale or foreign producers. Native
  recovery revalidates full selected bytes instead of reconstructing a preview.
- **Source preservation and failure isolation:** independent literal oracles
  and native files retain BOM/CRLF/mixed endings, meaningful spaces, unknown and
  hidden regions, unsupported encoding and EOF conventions. Rich marks,
  scene/speech/dual relationships and edited-source Undo are checked separately
  from bytes. External divergence refuses a guessed overwrite; emergency copy
  preserves local work beside external work. History-store failure cannot
  prevent ordinary source saving. Unrepresentable splits remain visible and
  copyable without fabricating portable Fountain syntax.
- **Privileges and egress:** default command registration excludes proof-only
  endpoints. Custom envelopes expose opaque registrations and destination
  tokens; capability permissions remain event listening/window close. Native
  ownership, anchored publication and lease checks were not relaxed. Clipboard
  markup becomes inert text/declared editor content. Production source has no
  fetch/WebSocket/beacon/remote-font client; release CSP blocks the synthetic
  development-server request while real IPC works. This is source/resource/CSP
  evidence, not a packet capture or installed-offline certification.
- **Bounded work and resources:** normal captures coalesce before whole-source
  work and yield to input/render scheduling. Snapshot/recovery comparison reads
  serialize at the UI boundary, so mounting several choices does not reserve
  multiple maximum-sized native buffers simultaneously. Queue permits release
  on worker completion; failed presentation callbacks cannot grant durability.
  Prior performance evidence supports the declared fixture, not arbitrary-size
  or long-session guarantees.
